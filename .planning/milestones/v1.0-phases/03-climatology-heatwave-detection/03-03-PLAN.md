```python
    value_property: str = "value",
    ward_id_property: str = "ward_id",

    flagged_fc: ee.FeatureCollection,
    min_consecutive_days: int | None = None,   # -> settings.climatology.min_consecutive_days (3)
    ward_id_property: str = "ward_id",
) -> ee.FeatureCollection: ...        # adds 'run_id' and 'event_id' (-1 when the run is too short)
```

Row schema after `detect_heatwave_events` (Phase 4 aggregates these into the covariate table):
```
ward_id            string   from heatwave/zonal.py
value              double   per-ward daily Heat Index
doy                int      1-366
system:time_start  long     millis
threshold          double   this ward's climatological threshold for this doy
is_hot             int      1 when value > threshold, else 0            -> CHAP `heatwave_days`
run_id             int      consecutive-hot-run id, -1 when not hot
event_id           int      run_id when the run length >= min_consecutive_days, else -1
                                                                        -> CHAP `heatwave_event_count`
                                                                           = count of distinct event_id != -1
```
