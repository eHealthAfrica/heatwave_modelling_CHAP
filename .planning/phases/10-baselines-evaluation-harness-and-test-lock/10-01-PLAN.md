<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| analyst code -> test rows | any loader request for split "test" must pass the lock |
| repo working tree -> lock | pre-registration file content and git state decide lock state |
| tests -> real data root | test processes must never write the real evaluation log or lock |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Information disclosure | test-split access before pre-registration | mitigate | require_open checks lock file, config hash, bundle sha, committed+clean pre-registration on every call; no bypass parameter |
| T-10-02 | Tampering | PREREGISTRATION.md edited after opening | mitigate | blob sha recomputed (hash-object vs rev-parse HEAD:) on each access, compared with TEST_LOCK.json |
| T-10-03 | Repudiation | evaluation_log.jsonl edits/truncation | mitigate | append-only open mode, fsync, prev_sha256 hash chain, verify_log_chain |
| T-10-04 | Tampering | tests polluting real log/lock | mitigate | session autouse fixture patches testlock._default_data_root to tmp |
| T-10-05 | Elevation of privilege | git subprocess injection / injected git runner | mitigate | private _git_runner delegating to artifacts._git list-form args, constant PREREG_RELPATH, "--" separators, no shell=True; no public git parameter |
| T-10-06 | Tampering | lock/bundle paths escaping data root | mitigate | bundle path must resolve inside forecast_runs_dir; stored relative without ".."; forecast_runs_dir refuses repo and frozen locations |
| T-10-07 | Spoofing | committed template satisfying "pre-registration committed" | mitigate | template uses a different filename and <<FILL>> placeholder rejected by open_lock |
| T-10-08 | Tampering | config validator bypass via new keys | mitigate | strict _build for evaluation section, min bounds incl. block_weeks >= 4 |
</threat_model>
