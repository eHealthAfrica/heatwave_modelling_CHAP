## Renderer API (`heatwave.forecast.evaluation.baselines_report`)
- `CAPTION_VALIDATION = report.CAPTION + "; validation 2015-2020"`, `LOCKED_NOTE` (formatted with `meta["test_runs"]`), `GENERATED_MARKER = "<!-- generated by scripts/forecast_baselines.py -->"`.
- `render_markdown(results_by_lead: {lead: LeadResult}, meta: dict) -> str`. Line 3 is the caption, the marker is the last line, "accuracy" never appears.
- meta keys used: run_id, generated_utc, data_version, parquet_sha256, config_sha256, seed, B, block_weeks, ci_level, reliability_bins, shrinkage_pseudo_count, n_wards, n_small_wards, n_large_wards, test_runs, best_baseline_by_lead, baseline_order, primary_leads, decay_check, sanity, mean_p_vs_obs, pin_override.
- Sections: Provenance, Best baseline per lead, Brier by lead (+ intervals), Skill against climatology, Skill against recent climatology (BSS with week-block and year-block CIs, dBS with week-block CI), Brier decomposition (REL and RES with week-block CIs, stated as conditional on bin edges), Season (MAM highlighted; all six leads in one table with the best baseline's BSS vs recent_climatology and its week CI), Region (all six leads: geozone, latitude band, all wards, large wards only, excluding LGA-average, LGA-average wards), Calibration-in-the-large by year (point values, no CI), Stratified ROC AUC (leads 1-2), Reliability (best baseline, leads 1-2, no interval claimed), Precision/recall/F1 (threshold, predicted-positive rate, prevalence, week-block CIs), Sanity checks, Notes (strawman climatology, trend extrapolation, 6-cluster year-block caveat, exploratory slices, fixed m, small-ward share, reanalysis labels).

## Script CLI (`scripts/forecast_baselines.py`, `main(argv) -> int`)
`python scripts/forecast_baselines.py [--data-root D] [--runs-root R] [--docs-out docs/forecast/BASELINES_VALIDATION.md] [--config forecast.yaml] [--expected-parquet-sha256 SHA] [--leads 1,2,...] [--train-leads 1,6|none] [--bootstrap-b N] [--force]`
- Exit 0 ok, 2 bad arguments. Refuses (exit 2): docs-out inside the frozen folder, outputs/ or keys/ (even with --force); docs-out not ending .md; docs-out outside docs/ without --force; existing file without the generated marker without --force; runs root inside the repo; `--bootstrap-b < 1`; leads not in config; train-leads not a subset of leads.
- Run folder gets `predictions/<baseline>_L<k>_validate.parquet` (and `_train` for train leads, rows with NaN p dropped), `baselines_results.json` (meta, thresholds, validate, train_diagnostics; NaN to null, `allow_nan=False`), `BASELINES_VALIDATION.md`, `RUN_MANIFEST.json`. Docs file written atomically. Prints run folder, docs path and the best baseline per lead.
