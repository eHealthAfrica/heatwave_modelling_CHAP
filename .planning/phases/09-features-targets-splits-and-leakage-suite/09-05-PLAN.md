## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store (fitted range) -> row table | a store fitted with held-out years must not feed training rows |
| cache directory on disk -> FeatureStore | files on disk become features on load |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-9-02 | Information disclosure (held-out into training) | lead_rows / build_fold_store | mitigate | fit_end guard (main split must equal splits.train_end; folds must equal fold.climatology_end); per-fold refit; poison test on the fold's validation years; embargo via split_masks/fold_masks |
| T-9-01 | Information disclosure (target in features) | lead_rows / build_issue_table | mitigate | features gathered at origin t from the as-of store; labels from targets.lead_label only; label column name never a registry feature (registry forbids heatwave_week) |
| T-9-04 | Tampering (path) | feature_cache_dir / save_feature_store | mitigate | path built from sha/hash hex only; refuse repo-internal and frozen-folder locations; atomic meta write |
| T-9-08 | Tampering (stale or crafted cache) | load_feature_store | mitigate | exact meta match (data sha, wards hash, names, fit range) or cache miss; numpy load with allow_pickle=False; dtype/shape checks |
| T-9-07 | Denial of service (memory) | lead_rows on real train rows | mitigate | gathers per feature in float32; selection indices first; issue table built only for requested origins |
