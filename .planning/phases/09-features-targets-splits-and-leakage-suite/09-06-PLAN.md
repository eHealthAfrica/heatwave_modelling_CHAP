Research test recipe: compare with np.testing.assert_array_equal (NaN-aware, bit-exact by construction); 50 sampled origins on a 6-ward x ~640-week panel run in seconds.
Comparison tolerance: the truncation and poison checks are bit-exact for integer and indicator features (lags of hd/hn/hw, hw fractions, base rate: integer sums in float64). For non-integer rolling features (anomaly windows, spatial means), use exact equality first. Only if that flakes, allow a tolerance of a few ULPs via np.allclose(rtol=0, atol=1e-6, equal_nan=True), as an explicit `atol` parameter of the check, documented in leakage.py. The reason: float summation order can differ between window lengths, and a real leak shows up as an O(1) difference, far above 1e-6. The mutation tests must still fail under that tolerance.
Budget: about 170 feature builds in the synthetic suite (50+ origins x (truncation + 2 poison modes), plus row-level and mutation runs) on the 6-ward panel, under 30 s in total; base_rate is vectorised over t (09-04 Task 2), so each build takes milliseconds.
